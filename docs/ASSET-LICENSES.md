## 3. AI-Generated Asset Disclosure

* **Current Status**: All core brand logos, vector emblems, CSS styling, UI layouts, and primary OpenGraph graphics were authored in-house.
* **Future AI Asset Protocol**: Any future promotional imagery or illustrative background assets created using AI generators (e.g. Midjourney, DALL-E, Stable Diffusion) must be logged in this register with tool name, prompt history, commercial usage rights verification, and platform terms check prior to deployment.
