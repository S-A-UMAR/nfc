01. Verified Infrastructure & Cloud Partners

Below is the complete, audited directory of third-party platforms utilized by {{ BRAND_NAME }}:

1. Paystack Payments Limited

PAYMENT GATEWAY

Role: Secure checkout and payment processing for physical NFC cards, accessories, and web solutions.

  • Data Handled: Transaction amounts, currency (NGN), customer email address, and cryptographic transaction reference tokens.
  • Security & Compliance: Certified PCI-DSS Level 1 service provider regulated by the Central Bank of Nigeria (CBN).

2. Brevo (Sendinblue SAS)

TRANSACTIONAL EMAIL

Role: High-deliverability transactional messaging, including 6-digit email OTP verification codes and password reset tokens.

  • Data Handled: Recipient email address, verification codes, and automated system alerts.
  • Security & Compliance: Headquartered in France; strict compliance with European GDPR, ISO 27001 certified, TLS 1.3 email encryption in transit.
  • Privacy Policy: brevo.com/legal/privacypolicy

3. TiDB Cloud (PingCAP, Inc.)

SERVERLESS CLOUD DATABASE

Role: Distributed, highly available relational MySQL database cluster hosting account data, cards, and interaction records.

  • Data Handled: Encrypted customer account records, profile details, smart card hardware assignments, orders, and first-party analytics.
  • Security & Compliance: SOC 2 Type II, ISO 27001, end-to-end TLS/SSL mandatory connection encryption, hosted on enterprise AWS European infrastructure (Frankfurt).
  • Privacy Policy: pingcap.com/privacy-policy

4. Cloudinary Ltd

MEDIA STORAGE & CDN

Role: Persistent storage, optimization, and edge delivery for user-uploaded profile pictures and digital card media.

  • Data Handled: Avatar photos and images uploaded by account holders to customize their profile cards.
  • Security & Compliance: SOC 2 Type II, ISO 27001 certified global media CDN.
  • Privacy Policy: cloudinary.com/privacy

5. Render Services, Inc.

APPLICATION HOSTING

Role: Containerized application runtime, WSGI web server hosting, and automated SSL certificate management.

  • Data Handled: Ephemeral server request logs, application runtime execution.
  • Security & Compliance: SOC 2 Type II, automated TLS/HTTPS encryption, DDoS mitigation.
  • Privacy Policy: render.com/privacy

6. Google Fonts (Google LLC)

WEB FONTS CDN

Role: High-performance content delivery network for typography assets (Sora, Inter, JetBrains Mono).

  • Data Handled: Client IP address and HTTP User-Agent header (transmitted automatically by client browsers when retrieving font stylesheets).
  • Security & Compliance: Fonts are served over HTTPS without cookies; requests are processed in accordance with Google's API Privacy Policy.
  • Privacy Policy: policies.google.com/privacy
